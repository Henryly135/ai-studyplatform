## 文档维护规则

- 新增中文文档时，同步新增对应英文 `.en.md`。
- 文档只记录项目本身，不保留无关团队、课程项目或外部仓库上下文。
- API、架构、部署和测试文档优先写成面试可讲清楚的总结，再链接到代码目录。
