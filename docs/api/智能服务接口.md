# AI 服务接口说明

本文档记录 `ai-service` 当前对外和内部接口。接口方法、路径、参数名、环境变量名属于系统契约，保持原样；说明文字使用中文。

## 健康检查

- `GET /`：返回服务运行信息。
- `GET /health`：返回健康状态。
- `GET /demo/health`：返回 AI 运行时健康状态。

## 对话接口

- `POST /chat`：提交 AI 对话请求，支持课程或模块上下文。请求中的 `model_id` 只表示聊天模型；后端从模型目录派生对应向量模型。
- `GET /chat/sessions`：查询当前用户的对话会话。
- `GET /chat/modules/{module_uuid}/sessions`：查询指定模块的对话会话。
- `GET /chat/sessions/{session_uuid}`：查询单个会话详情和消息。
- `POST /demo/chat`：兼容旧入口的对话接口，前端主流程已使用认证后的 AI 工作区。

聊天成功响应包含实际聊天模型、实际向量模型、检索模式和资料来源，便于确认页面选择、查询向量与生成调用一致。普通用户不能通过请求体独立覆盖向量模型。

课程检索使用所选聊天模型配对的精确 `embeddingModelId + embeddingVersion` 检查覆盖率。只有无已发布资料的 `empty` 状态允许普通聊天；`partial`、`not_indexed`、`building`、`failed` 返回 HTTP 503 / `AI_RAG_INDEX_NOT_READY`，模型组合不可用返回 HTTP 503 / `AI_RAG_PROVIDER_UNAVAILABLE`。

## 模型目录

- `GET /models`：返回当前用户可用的聊天模型、管理员默认模型和用户历史选择。

模型目录只包含 Gemini、GLM 和 OpenRouter。每个聊天模型包含后端维护的配对向量模型、1024 维信息、RAG 就绪状态和索引覆盖率；不返回 Provider Key。
请求携带 `courseUuid`/`moduleUuid` 以查询范围化覆盖率时，接口会先复用课程聊天的访问校验，未授权用户不能读取该范围的索引状态；`moduleUuid` 不能脱离 `courseUuid` 单独使用。

聊天模型解析优先级为请求显式选择、仍可用的用户历史选择、管理员默认模型和初始化默认值。系统工作流不读取普通用户偏好。

## 管理员模型与凭据接口

- `GET /admin/ai/providers`：查询三个 Provider 的脱敏凭据状态、模型目录和默认模型组合。
- `PUT /admin/ai/providers/{provider_key}/credential`：保存或覆盖 Provider Key。
- `DELETE /admin/ai/providers/{provider_key}/credential`：删除 Provider Key。
- `POST /admin/ai/providers/{provider_key}/health-check`：执行聊天与 Embedding 能力健康检查。
- `PATCH /admin/ai/defaults`：设置默认聊天模型；响应同时返回后端派生的默认向量模型。

删除凭据后，该 Provider 的聊天模型不可选；历史调用审计保留。保存新凭据后，系统可为现有知识块创建该 Provider 的向量回填任务。

## 学习画像接口

- `POST /profiles/global/init`：初始化当前学习者的全局学习画像。
- `GET /profiles/global/me`：读取当前学习者的全局学习画像。
- `POST /profiles/module/{course_uuid}/{module_uuid}/init`：初始化模块级学习画像。
- `GET /profiles/module/{course_uuid}/{module_uuid}`：读取模块级学习画像。

## 测验生成接口

- `POST /courses/{course_uuid}/modules/{module_uuid}/quiz/authoring/generate`：为教师生成可编辑的测验草稿。
- `POST /courses/{course_uuid}/modules/{module_uuid}/quiz/generated-attempt-sessions/auto`：为学生创建自动生成的测验尝试。
- `POST /courses/{course_uuid}/modules/{module_uuid}/quiz/generated-attempt-sessions/auto/stream`：以流式事件返回自动生成测验的执行进度。

测验检索、规划和出题固定使用工作流开始时解析出的管理员默认模型组合，不读取教师或学生偏好。只有向量覆盖状态为 `ready` 才继续；无已发布资料返回 HTTP 409 / `AI_RAG_NO_MATERIALS`，其他未就绪状态返回 HTTP 503 / `AI_RAG_INDEX_NOT_READY`。

## 管理员 AI 观测接口

- `GET /admin/telemetry/summary`：汇总 AI 调用、检索、嵌入、索引和聊天指标。
- `GET /admin/telemetry/trends`：查询 AI 指标趋势。
- `GET /admin/telemetry/anomalies`：查询异常指标。
- `GET /admin/telemetry/failures`：查询失败审计记录。
- `GET /admin/telemetry/failures/export`：导出失败审计记录。
- `GET /admin/telemetry/provider-config`：查询模型和供应商配置状态。
- `GET /admin/telemetry/provider-health`：查询供应商健康状态。
- `GET /admin/telemetry/governance`：查询 AI 治理指标和告警。

供应商状态仅覆盖 Gemini、GLM 和 OpenRouter；向量状态按 Provider、模型、版本和资料统计，不能用聊天健康状态代替索引就绪状态。

## 任务接口

- `POST /tasks/smoke`：创建后台任务测试。
- `GET /tasks/smoke/{task_id}`：查询后台任务测试结果。
- `GET /tasks/index-jobs/{job_id}`：查询资料索引任务状态。

## 内部索引接口

- `POST /internal/index-jobs/material`：创建资料索引任务。
- `POST /internal/index-jobs/material/delete`：创建资料删除索引任务。
- `POST /internal/index-jobs/release`：发布索引任务。
- `POST /internal/index-jobs/{job_id}/retry`：重试指定索引任务。
- `POST /internal/index-jobs/recover-stale`：恢复停滞索引任务。

## 内部画像接口

- `GET /internal/profiles/global-exists/{learner_id}`：检查学习者全局画像是否存在。
- `POST /internal/profiles/module/init-batch`：批量初始化模块画像。
- `POST /internal/profile-update/context`：构建画像更新上下文。
- `POST /internal/profile-update/candidate`：提交画像更新候选内容。
- `POST /internal/profile-update/run-check`：执行画像更新检查。

## 内部测验生成接口

- `POST /internal/quiz-generation/run`：执行内部测验生成工作流。
