# 身份服务接口说明

本文档记录 `identity-service` 当前接口。接口方法、路径、字段名和环境变量名保持原样；说明文字使用中文。

邮件验证、密码重置和教师邀请链接使用服务端配置的公开前端地址：`PUBLIC_FRONTEND_URL`，或去掉 `/api` 后缀的 `PUBLIC_BASE_URL`。生产环境拒绝缺失、`localhost` 或非 HTTPS 的公开前端地址；请求头 `Origin` 和 `x-public-frontend-url` 只用于本地开发兜底。

## 健康检查

- `GET /`：返回服务运行信息。
- `GET /health`：返回健康状态。

## 认证接口

- `POST /auth/register`：注册普通用户。
- `POST /auth/login`：登录并返回访问令牌。
- `GET /auth/verify-email`：验证邮箱。
- `POST /auth/resend-verification`：重新发送邮箱验证邮件。
- `GET /auth/me`：查询当前用户。
- `POST /auth/forgot-password`：发起密码重置邮件。
- `POST /auth/reset-password`：使用重置令牌设置新密码。
- `GET /auth/me/permissions`：查询当前用户权限。
- `POST /auth/change-password`：登录后修改密码。
- `GET /auth/invite/educator/validate`：校验教师邀请令牌。
- `POST /auth/register-educator-invite`：通过邀请链接注册教师账号。

## 管理员接口

- `GET /admin/users`：查询用户列表。
- `PATCH /admin/users/{user_uuid}/identity`：更新用户身份。
- `PATCH /admin/users/{user_uuid}/status`：更新用户状态。
- `GET /admin/educator-approvals`：查询待处理教师审批。
- `GET /admin/educator-approvals/history`：查询教师审批历史。
- `GET /admin/educator-approvals/{request_uuid}`：查询教师审批详情。
- `PATCH /admin/educator-approvals/{request_uuid}`：处理教师审批。
- `POST /admin/educator-invite-tokens`：生成教师邀请令牌。
- `POST /admin/educator-invite-tokens/{invite_uuid}/send-email`：发送教师邀请邮件。
- `GET /admin/educator-invite-tokens`：查询教师邀请令牌。

## 内部接口

- `POST /internal/users/lookup`：供内部服务按用户标识查询用户信息。
