# 通信服务接口说明

本文档记录 `communication-service` 当前接口。接口方法、路径和字段名保持原样；说明文字使用中文。

## 健康检查

- `GET /`：返回服务运行信息。
- `GET /health`：返回健康状态。
- `GET /ready`：返回服务就绪状态。

## 课程论坛

- `POST /courses/{course_uuid}/forum-posts`：在课程论坛创建帖子。
- `GET /courses/{course_uuid}/forum-posts`：分页查询课程论坛帖子。
- `GET /forum-posts/{post_uuid}`：查询帖子详情。
- `PATCH /forum-posts/{post_uuid}`：更新帖子内容。
- `DELETE /forum-posts/{post_uuid}`：删除帖子。
- `POST /forum-posts/{post_uuid}/pin`：置顶帖子。
- `DELETE /forum-posts/{post_uuid}/pin`：取消置顶。
- `POST /forum-posts/{post_uuid}/comments`：创建帖子评论或回复。
- `GET /forum-posts/{post_uuid}/comments`：查询帖子评论。
- `GET /forum-comments/{comment_uuid}`：查询评论详情。
- `GET /forum-comments/{comment_uuid}/replies`：查询评论回复。
- `PATCH /forum-comments/{comment_uuid}`：更新评论。
- `DELETE /forum-comments/{comment_uuid}`：删除评论。

## 通知管理

- `GET /notifications`：管理员查询通知列表。
- `POST /notifications`：管理员创建通知。
- `GET /notifications/{notification_uuid}`：查询通知详情。
- `PATCH /notifications/{notification_uuid}`：更新通知。
- `DELETE /notifications/{notification_uuid}`：删除通知。

## 我的通知

- `GET /me/notifications`：查询当前用户收到的通知。
- `GET /me/notifications/unread-count`：查询未读通知数量。
- `POST /me/notifications/read-all`：将当前用户通知全部标记为已读。
- `GET /me/notifications/{notification_uuid}`：查询当前用户的通知详情。
- `PATCH /me/notifications/{notification_uuid}/read`：标记为已读。
- `PATCH /me/notifications/{notification_uuid}/unread`：标记为未读。
- `DELETE /me/notifications/{notification_uuid}`：隐藏通知。
- `PATCH /me/notifications/{notification_uuid}/restore`：恢复隐藏通知。

## 内部通知接口

- `POST /internal/notifications/system`：由其他服务创建系统通知。
