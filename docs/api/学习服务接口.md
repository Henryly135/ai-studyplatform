# 学习服务接口说明

本文档记录 `learning-service` 当前接口。接口方法、路径和字段名保持原样；说明文字使用中文。

## 健康检查与资料访问

- `GET /`：返回服务运行信息。
- `GET /health`：返回健康状态。
- `GET /ready`：返回服务就绪状态。
- `GET /materials/{path}`：访问已授权的学习资料。

## 课程目录

- `GET /courses/search`：搜索课程。
- `GET /courses`：查询课程列表。
- `GET /courses/{course_uuid}`：查询课程详情。
- `GET /courses/{course_uuid}/modules/{module_uuid}`：查询课程模块详情。

## 课程管理

- `POST /courses`：创建课程。
- `PATCH /courses/{course_uuid}`：更新课程。
- `DELETE /courses/{course_uuid}`：删除课程。
- `POST /courses/{course_uuid}/cover`：上传课程封面。
- `POST /courses/{course_uuid}/publish`：发布课程。
- `GET /courses/me/managed`：查询当前教师管理的课程。
- `GET /courses/{course_uuid}/management`：查询课程管理详情。

## 教学分析

- `GET /courses/me/analytics`：查询教师课程分析。
- `GET /courses/me/analytics/quiz`：查询测验分析。
- `GET /courses/me/analytics/teaching-insights`：查询教学洞察。
- `GET /courses/me/analytics/material-briefs`：查询资料摘要。

## 报名与进度

- `GET /courses/{course_uuid}/enrolments`：查询课程报名列表。
- `POST /courses/{course_uuid}/enrolments`：报名课程。
- `DELETE /courses/{course_uuid}/enrolments/me`：当前用户退出课程。
- `PATCH /courses/{course_uuid}/enrolments/{learner_uuid}/status`：更新学生报名状态。
- `GET /courses/me/enrolled`：查询当前用户已加入课程。
- `GET /courses/me/progress-overview`：查询当前用户学习进度概览。

## 课程邀请

- `POST /courses/{course_uuid}/invite-links`：生成课程邀请链接。
- `GET /courses/{course_uuid}/invite-links`：查询课程邀请链接。
- `DELETE /courses/invite-links/{invite_uuid}`：停用课程邀请链接。
- `GET /invite/course/validate`：校验课程邀请令牌。
- `POST /invite/course/enrol`：通过邀请令牌加入课程。

## 模块管理

- `POST /courses/{course_uuid}/modules`：创建模块。
- `PATCH /courses/{course_uuid}/modules/reorder`：调整模块顺序。
- `PATCH /courses/{course_uuid}/modules/{module_uuid}`：更新模块。
- `POST /courses/{course_uuid}/modules/{module_uuid}/publish`：发布或归档模块。
- `PUT /courses/{course_uuid}/modules/{module_uuid}/prerequisite`：设置模块前置条件。
- `DELETE /courses/{course_uuid}/modules/{module_uuid}/prerequisite`：删除模块前置条件。
- `DELETE /courses/{course_uuid}/modules/{module_uuid}`：删除模块。

## 模块内容

- `POST /courses/{course_uuid}/modules/{module_uuid}/progress`：更新模块学习进度。
- `POST /courses/{course_uuid}/modules/{module_uuid}/materials/upload`：上传小文件资料。
- `POST /courses/{course_uuid}/modules/{module_uuid}/materials/uploads/init`：初始化分片上传。
- `GET /courses/{course_uuid}/modules/{module_uuid}/materials/uploads/{upload_session_uuid}/parts/{part_number}`：获取分片上传地址。
- `POST /courses/{course_uuid}/modules/{module_uuid}/materials/uploads/{upload_session_uuid}/complete`：完成分片上传。
- `DELETE /courses/{course_uuid}/modules/{module_uuid}/materials/uploads/{upload_session_uuid}`：取消分片上传。
- `DELETE /courses/{course_uuid}/modules/{module_uuid}/materials/{material_uuid}`：删除学习资料。

## 测验

- `PUT /courses/{course_uuid}/modules/{module_uuid}/quiz`：创建或更新模块测验。
- `GET /courses/{course_uuid}/modules/{module_uuid}/quiz/management`：查询测验管理详情。
- `POST /courses/{course_uuid}/modules/{module_uuid}/quiz/publish`：发布测验。
- `POST /courses/{course_uuid}/modules/{module_uuid}/quiz/questions`：新增题目。
- `PATCH /courses/{course_uuid}/modules/{module_uuid}/quiz/questions/{question_uuid}`：更新题目。
- `GET /courses/{course_uuid}/modules/{module_uuid}/quiz/active-session`：查询当前活动测验会话。
- `POST /courses/{course_uuid}/modules/{module_uuid}/quiz/attempt-sessions`：开始测验尝试。
- `POST /courses/{course_uuid}/modules/{module_uuid}/quiz/generated-attempt-sessions`：开始由 AI 生成题目的测验尝试。
- `POST /courses/{course_uuid}/modules/{module_uuid}/quiz/attempt-sessions/{attempt_session_token}/submit`：提交测验答案。
- `GET /courses/{course_uuid}/modules/{module_uuid}/quiz/attempts`：查询测验尝试历史。
- `GET /courses/{course_uuid}/modules/{module_uuid}/quiz/attempts/{quiz_attempt_uuid}`：查询单次测验尝试详情。

## 管理员接口

- `PUT /admin/courses/{course_uuid}/enrolments/{learner_uuid}`：管理员更新课程报名状态。

## 内部接口

- `POST /internal/ai-context/chat-access`：校验 AI 对话上下文访问权限。
- `POST /internal/course-access/forum`：校验论坛访问权限。
- `POST /internal/quiz-generation/learner-access`：校验学生测验生成访问权限。
- `POST /internal/quiz-generation/authoring-access`：校验教师测验生成访问权限。
- `POST /internal/quiz-generation/context`：提供测验生成上下文。
- `POST /internal/quiz-generation/questions/batch-create`：批量创建测验题目。
- `POST /internal/quiz-generation/generated-attempt-sessions`：创建生成式测验尝试会话。
- `POST /internal/profile-update/quiz-signal-summary`：提供画像更新所需的测验信号摘要。
