# 上线前第二阶段修复计划

更新时间：2026-08-03。本文把本地隔离演示以外的上线阻断项集中管理；不以“已有缓解措施”替代生产验收。

## 第一阶段已收敛的边界

- 登录的数据库、审计和角色查询异常转为可控的 `503`，并提供本地演示账号 HTTP 冒烟脚本。
- Gemini 已通过管理员健康检查和一次真实聊天链路验证；脚本不会输出 Key、令牌、提示词或回复。
- 平台托管资料改为短期、用户绑定的代理 URL；浏览器还必须携带由已认证学习接口签发的 HttpOnly 会话 Cookie。代理请求会实时复查账号状态、角色、课程注册、模块解锁和资料权限，不再向课程页面下发对象路径或 MinIO 预签名 URL。
- AI 对话已保存 `pending` / `failed` 状态、请求幂等 ID 和重试入口；失败不再留下不可见的孤立用户消息。
- 对班级专属模块采用默认拒绝：在权威班级成员关系落地前，客户端 `classId` 不再能够扩大课程目录、资料或 AI 上下文权限。

这些措施支持受控本地演示，但不能替代下列生产上线工作。

## P0：生产上线前必须完成

| 工作项 | 实施范围 | 验收标准 | 回滚 / 保护措施 |
| --- | --- | --- | --- |
| 接入 ClamAV | 在独立 `clamd` 服务中扫描上传内容；应用只通过固定协议调用，不执行租户提供的命令。 | EICAR、受损压缩包、超时和 `clamd` 不可用均进入隔离/拒绝路径；生产环境扫描不可用时 fail-closed；扫描结果和定义库版本可审计。 | 保留隔离对象和最小元数据；开关只允许在隔离开发环境关闭。 |
| 收敛 Docker 端口 | 生产 compose 仅暴露 nginx/TLS 入口；MySQL、PostgreSQL、Redis、MinIO 和内部 API 放入 internal network。 | `docker compose config` 与宿主机端口扫描均证明内部服务无主机监听；服务间 DNS、健康检查、备份和迁移正常。 | 提供仅开发使用的 `compose.override` 或 profile 显式开放调试端口，禁止带入生产。 |
| 真正流式资料索引 | 上传、抽取、分块和向量化使用有界 chunk/流，不把整段音视频、图片或 MinIO 对象读入进程内存或完整临时文件。 | 以限制内存的容器处理目标上限文件；峰值内存、超时、取消、断点恢复和失败重试有指标；索引结果与现有基线一致。 | 新旧索引器双跑并按材料/特性开关灰度；失败时保留已验证旧索引，不发布部分结果。 |

## P1：与 P0 并行设计、在正式扩大用户范围前完成

| 工作项 | 实施范围 | 验收标准 |
| --- | --- | --- |
| 班级成员权威授权 | 建立班级、成员关系和服务端来源；统一课程目录、资料代理、下载、AI 上下文、检索和管理端的判定。 | 同一用户/模块在所有入口得到一致结果；伪造或过期 `classId` 无法获得访问；转班、停用和撤销在短缓存窗口内生效。 |
| AI 历史记录性能 | 使用稳定游标分页、服务端搜索、批量课程/模块权限校验和必要索引，消除列表页 N+1。 | 百/千会话基准下查询数和 P95 可观测；游标无重复/漏项；搜索不泄露无权会话。 |
| 对话失败的运营闭环 | 为 `pending` / `failed` 状态增加超时回收、可观测指标、用户可见错误码、重试限额和幂等 ID 保留策略。 | 网络中断、重复提交、超时、供应商 429/5xx 都有可预测状态转换、审计记录和可恢复 UI。 |
| 代理链接运维 | 为资料代理增加访问审计、短期票据滥用告警、Identity 复查失败指标和下载吞吐监控。 | 课程退课、账号停用、角色撤销和资料删除后的拒绝均有审计；大文件 Range 播放和下载监控正常。 |

## 推荐实施顺序

1. 先在 staging 完成 Docker 端口收敛和 ClamAV，建立隔离/恢复演练。
2. 在不改变现有检索结果的前提下双跑流式索引，记录内存、延迟和失败率。
3. 上线班级成员数据模型后，删除当前“班级模块默认隐藏”的临时策略，改为统一服务端成员校验。
4. 完成 AI 历史游标和批量权限查询，再开放更大规模的会话历史与搜索。
5. 做一次故障演练：关闭 `clamd`、撤销课程注册、令牌重复提交、暂停 Provider、断开 MinIO；所有场景必须可观测且无越权数据返回。

## 发布门槛与证据

- 每项 P0 均需代码审查、自动化回归、staging 实测记录和回滚演练记录。
- 安全验收至少覆盖：未注册学习者、已退课学习者、非课程教师、管理员、被停用账号、过期/篡改代理 URL、伪造班级参数。
- 性能验收需保存受控测试规模、容器内存上限、P95/P99、数据库查询数和错误率。
- 生产部署前复核 `.env`：本地演示单账号关闭，默认账号/密码替换，所有内部端口未映射，Gemini Key 不写入日志或文档。
