# 后端测试说明

本文档记录后端测试方式、手动验证路径和常见失败排查。命令、接口路径、字段名和示例 token 名保持原样。

## 当前规则

- 公开 API 字段多数使用 camelCase，例如 `userName`、`accessToken`、`emailVerified`、`courseUuid`。
- AI 对话部分历史字段使用 snake_case，例如 `session_uuid`、`course_uuid`、`module_uuid`。
- 密码至少 8 位，并包含大写、小写、数字和特殊字符。
- 示例有效密码：`Password1!`。
- 前端和 nginx 默认地址通常是 `http://localhost:8080`。
- `identity-service` 暴露在 `/api`。
- `learning-service` 暴露在 `/api/learning`。
- `communication-service` 暴露在 `/api/communication`。
- `ai-service` 暴露在 `/api/ai`。

```bash
docker compose --env-file .env -f infra/docker-compose.yml down -v --remove-orphans
```


## 手动接口验证顺序

### 身份流程

1. 注册学生账号：`POST /api/auth/register`。
2. 注册教师账号或通过邀请链接注册教师。
3. 登录：`POST /api/auth/login`。
4. 查询当前用户：`GET /api/auth/me`。
5. 查询权限：`GET /api/auth/me/permissions`。
6. 修改密码和重置密码。
7. 管理员查询用户并修改用户状态。
8. 管理员处理教师审批或生成教师邀请。

### 学习流程

1. 教师创建课程：`POST /api/learning/courses`。
2. 教师创建模块：`POST /api/learning/courses/{course_uuid}/modules`。
3. 教师上传资料。
4. 教师发布模块和课程。
5. 学生查询课程目录并加入课程。
6. 学生打开模块并更新学习进度。
7. 教师创建和发布测验。
8. 学生开始测验、提交答案、查询结果。

### 通信流程

1. 学生或教师创建课程论坛帖子。
2. 查询帖子列表和详情。
3. 创建评论和回复。
4. 管理员或系统创建通知。
5. 用户查询通知、标记已读、隐藏和恢复。

### AI 流程

1. 上传资料后检查索引任务。
2. 在课程或模块上下文中发起 AI 对话。
3. 验证无权限用户不能检索其他课程资料。
4. 教师生成测验草稿。
5. 学生开始自动生成测验尝试。
6. 管理员查看 AI 运行状态、失败审计和供应商健康状态。

## 常见失败排查

### `401`

- token 缺失。
- token 已过期。
- 请求头不是 `Authorization: Bearer <token>`。

### `403`

- 当前角色无权限。
- 教师操作了不属于自己的课程。
- 学生访问了管理接口。
- 管理员接口未使用管理员账号。

### `422`

- 请求字段缺失。
- 字段类型不匹配。
- 枚举值不在允许范围内。

### AI 服务不可用

- `GEMINI_API_KEY` 未配置。
- 外部模型服务不可用或额度不足。
- PostgreSQL/pgvector 初始化失败。
- Redis 或 worker 未启动。

### MinIO 上传失败

- bucket 未初始化。
- 上传大小超过限制。
- nginx 代理路径不正确。
- 后端未生成授权访问地址。
